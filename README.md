# echo-server


# How to Run 

1. Make sure you have Python3 installed. 
2. Ensure that the ports used are accessible on your machine.
3. Run `python3 server.py` to begin the server listening process.
4. For each client, open a terminal window and run `python3 client.py`
5. Congrats! You have a TCP server serving multiple clients.

6. For RPC - You are able to open multiple clients talking to one server in order to run basic commands like ADD, SUBTRACT, MULTIPLY, and MAX!
